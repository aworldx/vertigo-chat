# Туду-лист для чата

Этот список фиксирует продуктовые идеи и договорённости для будущего планирования. Он не является спецификацией реализации.

## [x] Хит-парад музыки

Статус: сделано.

- Отдельная страница с отдельной кнопкой для перехода.
- Каждый участник загружает собственные треки. Предварительный лимит — до пяти треков на участника.
- Остальные участники могут ставить лайки; по числу лайков формируется топ любимых треков чата.
- Черновик приглашения: «Все мы любим слушать музыку. Загружайте сюда любимые треки, близкие вашему сердечку».

- Показывать иконку наушников рядом с пользователем в списке чатлан, когда он слушает музыку.
- По наведению на иконку показывать название текущего трека.
- Считать пользователя слушающим музыку, если он запустил трек в чате через вставленную команду или на странице хит-парада.

## [ ] Система опросов

- Администратор создаёт опросы в админке и видит статистику по ответам.
- Два типа вопросов:
  - оценка от 1 до 5 звёзд с необязательным комментарием — например, об удобстве общения, где 1 означает «очень плохо», а 5 — «супер»;
  - выбор из вариантов — например, «какие функции хотели бы видеть»; для каждого опроса задаётся режим одного или нескольких ответов.
- Зарегистрированный пользователь может ответить на каждый опрос только один раз.
- Для гостей на первом этапе: простое ограничение «один ответ на опрос с одного IP» с возможностью отключить это ограничение; без fingerprinting.
- Ограничение по IP не гарантирует уникальность человека: один общий IP может объединить нескольких людей, а смена IP позволяет ответить повторно. Для ожидаемой аудитории общая домашняя или офисная сеть считается маловероятной.

## [ ] Загрузка анимированных смайлов

- Это не эмодзи, а GIF-колобки в духе старой аськи и другие анимации.
- Пользователи загружают собственные смайлы; использовать их можно только после одобрения модератором.
- Нужна отдельная роль с правом модерировать смайлы.
- Нужны каталог или лента смайлов и вставка смайла в любое место текста сообщения на текущую позицию курсора с сохранением этой позиции.
- Согласованный интерфейс:
  - кнопка смайлов рядом с полем сообщения;
  - вкладки «Недавние», «Все» и «Мои»;
  - на компьютере — компактная панель;
  - на мобильном — нижняя панель с вертикально прокручиваемой сеткой;
  - во вкладке «Мои» отображается статус модерации каждого смайла.

## [ ] Оптимизация YouTube-видео для мобильных и одновременных просмотров

- Текущий прокси создаёт отдельные `yt-dlp` и `ffmpeg`-процессы для каждого зрителя
  и передаёт поток без byte-range; из-за этого воспроизведение может не запускаться
  в мобильном Safari, а один и тот же ролик скачивается повторно для каждого зрителя.
- Выбрать способ доставки: временный MP4-файл с поддержкой HTTP Range (`206 Partial
  Content`) или HLS с сегментами. Решение должно воспроизводиться в iOS Safari и
  Android-браузерах.
- Ввести общий кэш для одного ролика: ограничение размера, TTL, очистка устаревших
  файлов и защита от параллельного повторного скачивания одного video ID.
- Сохранить ограничение ролика до 20 минут и ограничить число одновременно
  подготавливаемых видео, чтобы защитить CPU, память, диск и исходящий канал VPS.
- Добавить наблюдаемость: число активных стримов, cache hit/miss, ошибки `yt-dlp` /
  `ffmpeg`, объём кэша и время подготовки ролика.
- Проверить вручную: старт, пауза и перемотка на iPhone Safari, Android Chrome и
  desktop Chrome; отдельный smoke-тест — несколько одновременных просмотров одного
  и разных роликов.
