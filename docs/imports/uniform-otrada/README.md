# «Возвращение „Отрады“» — перенос

Источник: https://vertigo.august4u.ru/gb/, сообщения 87–79, DOM-якоря
`mps_m_97`–`mps_m_89`. Все девять частей Uniform опубликованы 5 сентября 2026.
Разрешение Uniform — сообщение 89 от 30 сентября 2026, 00:28:41,
`mps_m_100`, в ответ на предложение moon о переносе на vertigo-chat.ru/library.
Пользователь подтвердил перенос и выбрал аккаунт загрузившего **moon**.

`source.json` — точный текст девяти блоков из DOM исходной страницы, включая
дисклеймер, абзацы, авторские опечатки и заключительные сведения о песне.
Никакой пересказ или литературное редактирование не выполняется.

`script/import-library-otrada.mjs` печатает транзакционный SQL. Он не подключается
к БД сам, проверяет аккаунт, ранг, лимиты и все девять частей. Повторное применение
идентичного набора ничего не меняет. Любой конфликт существующей серии блокирует
всю транзакцию; чужие статьи не обновляются и не удаляются. Схема 0012 должна
быть применена до импорта. Перед production-импортом сохранить бэкап БД.

Для репетиции допускается `fixture03`; production-значение по умолчанию — `moon`.
Автор произведения `Uniform` хранится отдельно от владельца `user_id`.
Источник и локальная обложка сохраняются при обычном редактировании статьи.
