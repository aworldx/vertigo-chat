# Автор произведения — дизайн до реализации

Точечное расширение принятой библиотеки v2 по запросу пользователя.
Фон, лампа, глобальная навигация, шрифты, карточки и сетка не меняются.

Эталоны созданы до изменения React и закреплены `FROZEN.sha256`:
1440×900, 1280×676, 768×1024, 390×844, Chromium, deviceScaleFactor 1.
Маршрут `/library`, авторизован fixture01. Те же три статьи и даты, что в v2;
у статьи 3 добавлена подпись Uniform. Редактор — новая пустая статья.
Список: `mock/`, редактор: `mock-editor/`; top, viewport, bottom.
Все шрифты и изображения унаследованы из v2 без замены.

Новая метаинформация: «Автор: Uniform» и «Опубликовал: fixture01» — отдельные
подписи в существующей строке, переносящиеся на мобильном экране. При пустом
авторе сохраняется прежняя строка с ником загрузившего. В редакторе одно
необязательное поле после названия, до серии. Предпросмотр обновляет атрибуцию.

Приёмка: точное сохранение chrome, фона/лампы, типографики, геометрии карточек;
соответствие новой строки/поля эталонам; отсутствие горизонтального overflow;
на каждом viewport и scroll-state необходимы actual, side-by-side, overlay/diff.
Публикующий аккаунт остаётся владельцем статьи: поле автора не меняет права.

Новые иллюстрации Uniform — содержание публикаций, не замена общего фона;
хранятся отдельно в `docs/imports/uniform-otrada/` и `apps/web/public/images/`.
