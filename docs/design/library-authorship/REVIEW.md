# Дизайн-ревью: автор произведения

Дата: 3 октября 2026. Результат: **принято** после успешного `verifier` в Docker.

Проверены независимые замороженные макеты, текущий Go + React UI с реальной PostgreSQL и парные изображения/наложения. Все перечисленные PNG лично открыты в этом проходе. Маршрут `/library`, Chromium, масштаб 100%, deviceScaleFactor 1, fixture01; список — три фиксированные статьи, редактор — пустая новая статья. Эталоны не изменялись после реализации.

Список: полное пиксельное совпадение всех 12 кадров. Редактор: максимум 3 отличающихся пикселя при пороге канала 12, максимальная средняя ошибка 0.087/255; геометрия, текст и фон визуально совпадают. Численные метрики — вспомогательные, не замена осмотра.

В таблице: C — chrome; G — высоты блоков/первый экран; T — типографика; B — фон; A — идентичность, crop, anchor и слой лампы/обложек; U — поля и кнопки; O — отсутствие горизонтального overflow; S — состояние прокрутки. PASS в каждой колонке относится к паре данного ряда.

## Положения на снимках: ожидаемое = фактическое

Координаты ниже приблизительно сняты с PNG, а не вычислены из CSS. `viewport` ограничен фактическим концом страницы, поэтому на коротком списке совпадает с `bottom`.

- Список 1440: верхние панели y=0–124, первая карточка y=336; лампа справа x≈1335–1439, y≈500–665. В viewport/bottom верх частично ушёл из кадра, первая карточка y≈255, лампа остаётся в той же точке фона, нижняя карточка заканчивается около y=836.
- Список 1280: панели y=0–124, первая карточка y=336; лампа x≈1185–1279, y≈382–534. В viewport/bottom первая карточка y≈31, последняя заканчивается около y=612; фон/лампа не образуют отдельный экран.
- Список 768: панели y=0–124, первая карточка y≈358; серии справа x≈448, лампа x≈648–767, y≈568–759. В viewport/bottom первая карточка y≈297, последняя заканчивается y≈877; лампа остаётся справа.
- Список 390: панели y=0–181, серии y≈415–526, первая карточка y≈593; лампа x≈322–389, y≈276–381. В viewport/bottom первая карточка y≈226, последняя заканчивается y≈812; лампа остаётся слоем позади карточек, а не перекрывает текст.
- Редактор 1440: верх диалога y=24, раздел формы/предпросмотра x≈778, первое поле y≈169, лампа видна затемнённой справа. В viewport/bottom диалог сдвинут вверх примерно на 31 px, нижняя граница y≈876; save доступна.
- Редактор 1280: верх y=24, раздел x≈698, первое поле y≈169. В viewport/bottom видна нижняя часть формы, save y≈571–623, граница диалога y≈652. Фон неподвижен, лампа затемнена за диалогом.
- Редактор 768: диалог x=24, y=24; первое поле y≈246; нижняя панель save y≈950–1012. Все scroll-state визуально одинаковы по существу: содержимое помещается, нет пустого второго экрана; лампа видна узкой затемнённой полосой справа.
- Редактор 390: диалог x=12, y=12, первое поле y≈226, toolbar y≈508–665; нижняя панель y≈770–831. При viewport/bottom верх формы уходит за кадр, toolbar y≈280–437, текстовое поле заканчивается y≈631, пояснения и save доступны. Декорация остаётся за диалогом.

## Репетиция произведения

Дополнительно лично открыты [desktop](review/community/otrada-1440.png) и [mobile](review/community/otrada-390.png): исходный текст читаем, автор Uniform и загрузивший fixture03 различимы; сюжетная обложка — отдельный контент, общий фон и лампа сохранены. Это проверка реальных данных, не подмена эталона. Тест также подтвердил 9 точных частей, порядок, отсутствие дублей, отказ от перезаписи при конфликте, источник и редактирование только загрузившим. Production-результат этим отчётом не заявляется.
