# Проверка темы «Ницца · Светлая»

2026-10-05. Итог: **APPROVED** для перечисленных состояний Chromium Linux Docker.
Реализация соответствует подготовленным PNG; функциональный verifier выполнен основным агентом.

## Условия сравнения

Маршрут `/chat`, guest `nice-designer`, 6 сообщений + системное сообщение, три участника (гость, бот Клэр, зарегистрированный moon со звездой), один poll notice. Точные fixtures — capture-extended.mjs и capture-actual.mjs. Locale ru-RU, Europe/Moscow, zoom 100%, device scale 1, reduced motion. Reference: исходный Docker-сервер 4063 + подготовленные proposal.css/extension.css. Actual: текущая сборка 4092, без CSS-инъекции. Одинаковые авторизация, данные и viewport в каждой паре.

История и фиксация эталонов описаны в HANDOFF.md. Новые references меню после замечания о бледных названиях сохранены до изменения соответствующего CSS приложения. Все предыдущие меню сохранены в before-command-contrast/. Остальной дизайн не подгонялся под реализацию.

Каждая тройка открыта основным агентом через контактные листы review-WIDTH.png (оригинал, actual, side-by-side, overlay, diff); дополнительно пересмотрены все обновлённые меню в commands-review.png, исходный/текущий desktop/mobile и реальные private/pet/player снимки. Полноразмерные оригиналы сохранены по ссылкам ниже. Side-by-side содержит два снимка исходного масштаба; overlay/diff имеют размер viewport.

## Положение композиции: expected = actual

| Viewport | Header и основной контент | Фон и объекты | Прокрутка |
|---|---|---|---|
| 1440×900 | Шапка вверху, лента слева, участники справа, ввод у нижней границы | Negresco справа, белый стул и кремовый кот внизу справа; список выше головы кота | Короткая fixture помещается: top/viewport/bottom совпадают, внешний документ не сдвигается |
| 768×1024 | Верхняя шапка, лента слева от участников, ввод внизу | Набережная и белый стул справа; кот в нижней правой области | Контент виден в первом экране, фон неподвижен при прокрутке ленты |
| 390×844 | Компактная шапка, одна колонка сообщений, двухрядный ввод внизу | Cover-crop справа, фрагмент стула/кота за лентой; отдельной фигуры нет | Лента прокручивается внутри области, шапка и ввод не дублируются |
| 844×390 | Низкая шапка, короткая лента, ввод внизу | Cover-crop, стулья справа; рисунок не перекрывает кнопки | Верх/середина/конец проверены; нет дополнительного пустого экрана |
| 320×568 | Шапка с меню, узкая лента, ввод внизу | Согласованный фрагмент белого стула/кота за панелями | Текст переносится, меню прокручивается, нижний ввод остаётся доступен |

В plain меняется только поверхность ленты: молочная общая панель. В hidden тот же источник композиции без кота. В player раскрытая панель занимает правую нижнюю область desktop/tablet/landscape, интерактивный target кота скрыт; на телефоне плеер сохраняет компактное поведение. В settings диалог перекрывает основной экран и сохраняет доступ к сохранению.

## Точные артефакты и критерии

C = chrome; H = высоты блоков/первый экран; T = типографика; B = фон;
A = идентичность, crop, anchor и layering набережной/стульев/Кармика;
U = controls; O = отсутствие горизонтального overflow; S = указанное scroll/state.
PASS в каждой колонке относится именно к viewport и состоянию данной строки.
В режимах без кота A проверяет пустой стул. Позиции expected/actual зафиксированы выше по открытым изображениям.

Максимальная разница 0.002392% (31 пиксель desktop, x1190–1369, y754 — одна строка на границе интерактивной области кота), без видимого сдвига композиции. Порог сравнения канала 12/255; допустимая площадь 0.05%. Hidden/player и остальные размеры: 0% пикселей выше порога.
