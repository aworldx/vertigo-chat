# Свет за стеклом — реализация утверждённого макета

UI review: PASS на пяти viewport и в обоих режимах. Эталоны LIGHT-FROZEN.sha256 сохранены до изменения рабочего CSS. Route http://127.0.0.1:4063/chat, Chromium DPR1 zoom100%, guest glass-designer, ru-RU/Europe/Moscow, fixture из capture-light.mjs. В actual CSS не подменяется. PNG mock/actual/overlay/diff лично просмотрены на контактных листах всех 50 состояний. Каждая строка PASS означает chrome, первый экран/высоты, типографика, фон, идентичность/масштаб/положение/слои девушки и кота, controls, overflow, scroll-state — PASS. Фигура остаётся справа ниже шапки, отражения видны сверху и слева; при прокрутке фон не становится отдельным экраном, лента прокручивается внутри viewport. Шапка, ввод и кот остаются на прежних местах в mock и actual. Сетка и шрифты сохранены.
