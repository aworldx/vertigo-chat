# Свет за стеклом — предложение, не реализация

Предыдущая визуальная приёмка не закрывает замечание пользователя 13:26: верх и левая часть слишком плоские. Этот вариант меняет только освещение фона и материал панелей. Рабочий CSS не изменён.

Свет: холодный radial слева 3%/12%, янтарный 51%/-12%, мягкое диагональное отражение. Шапка/composer blur18px, карточки blur12px и тёмный градиент 62–72%; светлая кромка без новой внешней рамки ленты.

Критерии будущей реализации на каждом размере: без изменения chrome/типографики/сетки; фигура не возвращается под шапку; отражения видны сверху/слева, текст сохраняет контраст; framed не имеет общей панели; plain имеет общую панель; нет overflow; меню и настройки не обрезаны; фон не становится отдельным экраном при прокрутке. Пока только предложение: final acceptance требует отдельного актуального Docker build и тройки mock/actual/pair+overlay. Полноразмерные desktop/mobile макеты просмотрены; это не отчёт о завершённой реализации.
