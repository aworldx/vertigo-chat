# Макет с акцентом на переписке

Предложение от 2026-10-04 после пользовательского скриншота. Рабочая тема не изменена. Прежняя визуальная приёмка отозвана: пользователь отметил лишние рамки и потерю акцента на тексте.

PNG: `1440-top.png` (1440×900), `390-top.png` (390×844), абсолютный корень `/Users/amirhasanov/Projects/chat/docs/design/chat-glass/mock-reading/`. Route `/chat`; Docker Chromium, zoom 100%, DPR 1, ru-RU, Europe/Moscow; guest glass-designer. Fixture: 6 сообщений, одно служебное событие, приватное приглашение в опрос, 3 участника. Данные и рендер сохранены в `../capture-reading.mjs`; стили в `../proposal-reading.css`, поверх исходного `../mock-app.css`. На mobile опрос ниже первого экрана, доступен прокруткой ленты.

Ресурсы: `/images/vertigo-glass-evening-v2.png`, существующие Oswald/Manrope, значки и спрайт Кармика. Сохранены навигация, список участников, composer и действия сообщений. Предложено убрать внутренние рамки сообщений и капсулы служебных событий; внешние границы ослаблены; текст расположен на более плотной общей подложке. Фон справа сохраняется, верх списка участников получает локальное затемнение. Опрос выглядит компактным уведомлением с вертикальным акцентом.

До реализации требуется выбор направления пользователем. Критерии дальнейшей сверки: отсутствие капсул, контраст текста, сохранение рисунка справа и mobile crop, реальные controls/chrome, scroll и меню без перекрытия. Этот набор — макеты, а не заявление о готовности реализации.
