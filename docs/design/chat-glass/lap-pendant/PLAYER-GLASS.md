# Макет стеклянного плеера

Предложение дизайна, не внедрение. Корень артефактов: `/Users/amirhasanov/Projects/chat/docs/design/chat-glass/lap-pendant/player-glass`.

Маршрут `/chat`, гость glass-designer, тема vertigo_glass, сообщения в рамках, включён личный плеер. Fixture чата из capture-player-glass.mjs; музыкальная очередь: «Чатлане — Ночной трамвай», «Тёплый вечер», «Огни города». Используется локальное тестовое аудио apps/web/browser/fixtures/player.webm, воспроизведение поставлено на паузу. Фон ../scene-partial-glass.png, стили предложения ../player-glass.css; шрифты и элементы управления текущего приложения. Device scale 1, zoom 100%, reduced motion.

PNG: 1440×900, 768×1024, 844×390 — expanded/compact, top/viewport/bottom. 390×844 — inline-only, поскольку текущая функция отдельного плеера отключена на ширине <768; новая мобильная функция не добавлена.

Зафиксированное направление: тонкая светлая рамка, радиус 16px, прозрачный зелёно-янтарный градиент, backdrop blur 5px, прозрачная музыкальная визуализация, золотисто-мятные столбики, тёмная полупрозрачная подложка подписи. Видео сохраняет непрозрачный экран. В полном режиме персонажи видны сквозь размытие; в компактном открыты полностью. Нажатие на Кармика сквозь плеер не предусмотрено: управление плеером имеет приоритет.

Критерии будущей приёмки для каждого viewport: окружающий чат, фон и crop совпадают с исходным макетом; типографика и существующие кнопки сохранены; прозрачность и рамки соответствуют PNG; переписка и composer не перекрыты; горизонтального overflow нет. Для узкого мобильного экрана отдельный dock отсутствует согласно текущему поведению.

Подготовка в Docker: вход, настройка, reload, заполнение очереди, кнопки play/pause и expanded/compact, отсутствие горизонтального overflow на трёх широких размерах, отсутствие toggle на 390. Снимки сохранены. Просмотрены desktop expanded/compact и tablet expanded. Полная приёмка реализации не проводилась: изменение существует только как макет; комплект сравнения с реализацией пока неприменим.
