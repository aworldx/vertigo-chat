# Стекло — Кармик на коленях

Статус: предложение макета, без изменения приложения или production. Иллюстрация создана встроенным imagegen по двум локальным референсам: `apps/web/public/images/vertigo-glass-evening-v2.png` и `apps/web/public/images/karmik-black-concept-v1.png`.

Задание генерации: сохранить интерьер, рифлёное стекло, зелёно-янтарную палитру и внешность девушки; посадить её, разместить исходного чёрного кота с янтарными глазами на её коленях и добавить круглый чёрно-белый кулон инь-янь на тонком ошейнике. Сохранить внешность кота, не добавлять текст или UI. Итоговый ресурс: `scene.png`.

Фон использует `scene.png`; остальные ресурсы и шрифты — текущего Docker-приложения. Исходный отдельный кот скрыт только в макете, чтобы избежать дублирования. На desktop/tablet фон смещён на 70 px вправо; размытие боковой панели отключено для читаемости кота и кулона.

## Критерии будущей реализации

Для каждого размера: PASS только если навигация, типографика, сообщения, интервалы и composer совпадают с PNG; фон использует именно scene.png и тот же crop; нет второго кота; на desktop/tablet девушка и кот находятся в правой декоративной области; нет горизонтального overflow. На mobile фон остаётся за сообщениями, поэтому девушка и кулон частично перекрыты перепиской — это сохранённая композиция мобильной темы, а не отдельная карточка персонажа.

Интерактивное поглаживание Кармика потребует отдельного решения при реализации: текущий макет объединяет кота с фоном. Макет не подтверждает готовность этой интеракции.

В Docker браузере сформированы все размеры и состояния, открыты меню команд и настройки; вход, применение темы и reload выполнены. Это подготовка макета, не финальная приёмка реализации: актуального реализованного изменения и комплекта comparison/diff пока нет.
