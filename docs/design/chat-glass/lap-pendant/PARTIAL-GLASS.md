# Стекло позади девушки — уточнение макета

Вторая версия по пожеланию пользователя: основное стекло позади девушки и кота, край переднего стекла слегка перекрывает плечо и платье. Лицо, Кармик и кулон остаются перед стеклом.

Ресурс: `scene-partial-glass.png`. PNG макетов: `mock-partial-glass/`; размеры, маршрут, состояние гостя и fixture совпадают с README.md. Прежний вариант сохранён отдельно. Это предложение дизайна, а не реализация функции.

Критерий иллюстрации: стеклянные полосы не проходят через лицо девушки, кота или кулон; край перегородки перекрывает только часть силуэта; внешность и поза совпадают с исходной сценой. Остальные критерии каждого viewport — в README.md.
