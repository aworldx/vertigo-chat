# Vertigo Glass — уточнение 4 октября 2026

Основа: исходный Docker `/chat`, `baseline/`. Упрощённый `mock.html` прежнего прохода не был PNG-эталоном и подменял часть навигации. Этот проход сохраняет реальные элементы интерфейса и исправляет пользовательские замечания: скруглённые отдельные секции, прозрачность, видимость фигуры на телефоне.

До изменения рабочего CSS зафиксированы `proposal.css`, `mock-app.css` и PNG `mock/{width}-{state}.png`. Route `/chat`; Chromium Docker, zoom 100%, deviceScaleFactor 1, ru-RU, Europe/Moscow; guest `glass-designer`, frame=true. Для сопоставимости браузер получает фиксированный визуальный WebSocket fixture: 24 сообщения, три участника, точные тексты/время/appearance в `capture.mjs`. Вход и сохранение темы выполняются настоящим API; визуальная подмена данных не является функциональным тестом отправки.

Для каждого размера абсолютный корень PNG: `/Users/amirhasanov/Projects/chat/docs/design/chat-glass/mock/`. Например, `390-top.png`. Состояния scroll относятся к внутренней ленте: начало, одна высота видимой ленты и её нижняя граница. Дополнительно выполняется window.scrollTo; страница занимает 100dvh и не должна прокручиваться сама.

Ресурсы: `/images/vertigo-glass-evening-v2.png`; существующие локальные шрифты и иконки приложения (Oswald/Manrope), спрайт Кармика. Новых функций и пунктов меню нет. Панели: border 1px rgba(242,232,214,.32), desktop radius 20/18px, mobile 17/15px, outer spacing 14/16px и 10px, blur 1.5px. Сообщения: rgba(8,20,17,.52), radius 12px. Шрифт сообщений определяется личными настройками; fixture использует sans. Верхняя навигация, формы и действия сохраняют исходную типографику.

Критерии PASS на каждом viewport: реальные chrome/controls сохранены; фигура и исходный фон совпадают по crop и слоям; первый экран содержит сообщения и ввод; размеры/шрифты/отступы совпадают с PNG; нет горизонтального overflow; меню команд не обрезано панелью; настройки видны с доступными кнопками закрытия и сохранения; все три scroll-state сохраняют панели и фон на месте. Финальная сверка требует mock PNG, actual PNG, side-by-side и overlay/diff для каждой строки. До такой сверки визуальная приёмка не заявляется.
