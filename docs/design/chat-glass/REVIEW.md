# Vertigo Glass — финальная проверка 4 октября 2026

> Архивная приёмка отозвана после пользовательского скриншота 12:48. Актуальные эталоны и результат двух режимов: [MODES-REVIEW.md](MODES-REVIEW.md). Ниже сохранён исторический отчёт предыдущей версии.

Результат: PASS для выбранного пользователем reading-first дизайна с чёрным Кармиком. Предыдущий прозрачный вариант отклонён после пользовательского скриншота и не используется как эталон. Подтверждены отсутствие капсул у служебных событий, более плотная подложка текста и мягкие границы секций.

Route: `http://127.0.0.1:4063/chat`, текущие статические файлы собраны в Docker (`chat-glass-web:local`) и установлены в локальный API-контейнер без изменения backend/БД. Chromium, DPR 1, zoom 100%, locale ru-RU, timezone Europe/Moscow, reduced-motion для статических кадров. Guest `glass-designer`; одинаковый визуальный fixture в `capture-final.mjs`: 6 сообщений, служебное событие, опрос, три участника. Подмена ограничена данными для визуальной сверки; функциональные проверки ниже работают с настоящим API без подмен.

До реализации сохранены PNG `mock-final`, дополняющие показанные пользователю `mock-black-cat` для tablet/landscape/320px и состояний меню. `FINAL-FROZEN.sha256` закрепляет эти PNG и предложения CSS. Используются исходные фон и кот: `/images/vertigo-glass-evening-v2.png`, `/images/karmik-black-concept-v1.png`, локальные шрифты Oswald/Manrope. На 320px отдельная ссылка «Хит-парад» скрывается, но остаётся в меню. Мобильная версия сохраняет отсутствие sidebar/Кармика.

Сравнение выполнено после verifier. Просмотрены контактные листы оригиналов, актуальных кадров, overlay и diff на всех пяти размерах, а также полноразмерные основные кадры. Во всех 25 сравнениях доля пикселей с разницей канала >12 равна 0%. Это не проверка звука или других браузеров.

В каждой строке PASS означает: chrome, высоты блоков/первый экран, типографика, фон, идентичность/crop/anchor/слои фигуры и кота, controls, отсутствие overflow, указанное scroll-state — PASS. Состояния top/viewport/bottom — прокрутка внутренней ленты; дополнительно window.scrollTo не смещает экран 100dvh. На широком экране короткая fixture помещается целиком, поэтому эти три состояния совпадают.

Функциональный verifier: `browser/glass-verification.ts` прошёл 1440×900, 768×1024, 390×844, 844×390, 320×568. Проверены прямой переход /chat до входа, вход, выбор темы, reload, реальная отправка и получение сообщения после reload, компактный режим, меню команд (включая hit-test отсутствия clipping), emoji picker, настройки, возврат к dark без стилей glass. На desktop поглаживание вызывает серверный happy и «Мур-р-р!», применяется karmik-glass-pet; reduced-motion отключает анимацию. Звук сохранён существующим обработчиком, аудиовывод вручную не прослушивался. Старые mobile personal-settings scenarios тоже прошли.

Статика: React typecheck/lint и 29 целевых unit-тестов ленты/connection/online — PASS; Go chatlans/domain — PASS. Production не обновлялся; commit/push не выполнялись. WebKit/Safari и Firefox в этом проходе не запускались. CSS предусматривает -webkit-backdrop-filter и непрозрачный fallback. Чёрный кот — одна иллюстрация с CSS-реакцией, а не покадровая анимация старого спрайта.
