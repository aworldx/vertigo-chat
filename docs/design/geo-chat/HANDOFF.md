# «Где мы?» — макеты общего раунда

Основной документ: [договорённости и визуальный эталон v1](AGREEMENTS.md).
Перед реализацией читать его: он фиксирует решения пользователя, открытые вопросы
и известное расхождение landscape-макета с требованием текстовых ответов на телефоне.

Статус UI: выбранные статичные макеты, не реализация игры. Отдельным этапом уже
подготовлены Go-импортёр и community-каталог; работающий интерфейс геоигры отсутствует.

Замороженные PNG: `reference-v1/mock-final/`, точные размеры и SHA-256 — в
`reference-v1/manifest.json`. `mock-final/` — рабочий оригинал, его дальнейшая
перегенерация не меняет эталон. Предыдущие `mock/` и `mock-words/` — исторические
варианты, не основание для реализации. На телефоне ответы только словами,
включая landscape; в текущем landscape PNG вкладка карты требует исправления
отдельным макетом до реализации. На desktop предусмотрена вкладка карты.
Открытая панель скрывает боковой список участников; при сворачивании список
возвращается. Кнопка «В чате · 3» предназначена для временного просмотра списка,
его поповер ещё не спроектирован.

## Предлагаемое поведение

Фото/таймер остаются на месте при прокрутке чата. На телефоне фото и ответ сверху, обсуждение и обычный ввод ниже. Поле игрового ответа отделено от сообщения в общий чат. Отправленная версия видна только автору; до конца времени предлагается разрешить её изменение. Это предложение, а не работающая приватность.

Предложены одинаковые правила за страну/город на разных устройствах, без преимущества точного клика по карте. До реализации необходимо определить баллы, синонимы/опечатки/одноимённые места, соответствие точки на карте текстовому ответу, подтверждение и смену ответа. Набор локаций должен содержать ожидаемые ответы и допустимые варианты.

## Критерии будущей приёмки

Для каждого viewport из таблицы PASS только при выполнении всех пунктов:

- Шапка, общий фон, шрифты, композер и карточки чата сохраняют baseline, кроме обусловленной игрой ширины ленты.
- Открытая игра скрывает боковой список; свернутая возвращает его. Просмотр участников доступен без завершения раунда.
- Геометрия панели, фото/crop, контраст, поля и состояния совпадают с соответствующим исходным PNG.
- На телефоне нет вкладки карты; игровое поле и обычный ввод чата визуально различаются.
- При верхней, средней и нижней прокрутке ленты панель не сдвигается, нет горизонтального переполнения или перекрытых контролов.
- Desktop/tablet/landscape и mobile отвечают по одинаковым правилам; ответы не попадают в общую историю до раскрытия.
- Подготовлены дополнительные макеты поповера участников, открытой клавиатуры, раскрытого фото, загрузки, ошибки и результата раунда до реализации соответствующих состояний.

Финальная приёмка реализации ещё не проводилась. Для неё обязательны verifier на актуальной Docker-сборке и тройки: исходный PNG, PNG реализации с теми же viewport/auth/fixtures, side-by-side плюс overlay/diff. Сейчас имеются только baseline и макеты. Unit/HTTP/PostgreSQL проверки не запускались: рабочая функция не менялась.
