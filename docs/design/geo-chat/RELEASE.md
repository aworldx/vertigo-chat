# Геоигра 0.24.0 — выпуск

## Объём

Изолированный worktree `codex/geo-release`, база `5ff4d4cdf70468694c8f1e4bdd07f3f101509ee9`. Параллельное удаление Phoenix в основном checkout не включается. Пользователь разрешил выпуск игры после проверок.

Пять раундов по пять минут; настоящие интерактивные Google-панорамы; городской приоритет; приватные ответы; постоянный рейтинг аккаунтов; меню «Рейтинги» с геоигрой и Тетрисом; явное закрытие; свёрнутый вход только во время активной игры. Ключи находятся только в окружении.

## Целевые проверки в закреплённом Linux Docker

- Go race: geogame domain/application/Google/HTTP/PostgreSQL, geocatalog, API composition, webdelivery, Karmik. PostgreSQL-проверки с реальной отдельной БД выполнены через `script/verify-go-geo`, включая повторное начисление и сохранение рейтинга после очистки партии.
- Frontend: 141 unit tests, TypeScript, ESLint/architecture, Prettier, build. Контракты geo/chat валидны; остаются предупреждения о метаданных лицензий и response documentation, ошибок нет.
- `script/verify-go-geo`: /chat/main напрямую и после reload, два посетителя, пять раундов, замена/приватность ответа, закрытие/открытие, свёрнутый вход без загрузки Google, отсутствие панели без активной игры, зарегистрированный рейтинг в двух партиях, гости исключены, отсутствие ключей.
- Native Google: реальная community-партия и карта выбора/геокодирование, осмотр/переход по улице/возврат, сохранение позиции между polling, телефон. Один временный отказ загрузки текстур показал повторную загрузку; отдельная повторная проверка прошла.
- /rankings: прямой вход/reload, геоигра/Тетрис, соревнования/соло и периоды, пустая таблица/ошибка/повтор.
- Соседние сценарии: chat PostgreSQL/browser и player; повторная целевая проверка Тетриса с PostgreSQL/browser (соло/offline/async/replay, трое игроков, наблюдатель, готовность, rematch, очки, пауза, звук, рейтинг, responsive).
- Строгий визуальный review: 69 состояний, [REVIEW.md](REVIEW.md). Панорамы/свёрнутый вход: 1440×900, 768×1024, 390×844, 844×390, 390×544; рейтинги — первые четыре размера. На каждом размере верх/прокрутка на viewport/низ. Макеты, Docker PNG, side и overlay сохранены вне контейнеров.

Полный `script/check` не запускался: по правилам проекта release gate состоит из целевых проверок. Голосование, галерея и библиотека не изменялись и отдельно не перепроверялись.

## Ограничения

Городской приоритет — эвристика адреса, а не гарантия отсутствия пустых дорог. Google может менять доступность панорам; не везде есть стрелки перехода. Успешная локальная проверка Google не заменяет проверку ограничений browser key на production-домене после выпуска.
