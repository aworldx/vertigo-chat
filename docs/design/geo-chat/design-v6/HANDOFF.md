# V6: восстановление сворачивания и игра вместе с плеером

Предыдущая приёмка не покрывала сочетание открытой игры с включённым плеером; после замечания пользователя она отозвана для этой поверхности.

Сохранить существующие фон, шрифты, цвета, отступы панели и кнопки. В заголовке вернуть отдельную кнопку «−» (доступное имя и tooltip «Свернуть игру») перед увеличением; «Закрыть ×» остаётся отдельным действием. Сворачивание из увеличенного состояния возвращает компактную полоску, не останавливает раунд; список чатлан возвращается.

У открытой игры список чатлан скрыт, включая работу плеера. Плеер не создаёт пустую боковую колонку: его существующая компактная строка занимает нижний ряд над вводом чата; развёрнутые органы управления используют существующий вид всплывающей панели справа. Сам media-элемент не переносится и не перемонтируется, звук продолжается. После сворачивания/закрытия игры возвращается прежняя раскладка плеера и списка. На телефоне сохраняется существующее inline-воспроизведение.

До реализации сохранить viewable PNG для 1440×900, 768×1024, 390×844, 844×390, 390×544: обычная и увеличенная игра; при ширине ≥768 дополнительно компактный и развёрнутый плеер. Верх / viewport-scroll / низ. /chat, гостевая сессия, ru-RU, Europe/Moscow, DPR1, zoom100%; точные fixture и файлы — artifacts.json. Google SDK в этих проверках заменён явным фото-fixture для воспроизводимости кнопок и раскладки; прогулка Google проверяется отдельно.

PASS/FAIL на каждом PNG: прежнее окружение, исходный фон и его crop/anchor/layering, шрифты, высоты и первый экран; три отдельные кнопки игры помещаются; нет боковой колонки со списком при открытой игре; плеер доступен и не прерывается; нет горизонтального overflow; правильное положение после каждого scroll. После реализации обязательны новые Docker PNG, side и overlay/diff одинаковых размеров и личный просмотр.
