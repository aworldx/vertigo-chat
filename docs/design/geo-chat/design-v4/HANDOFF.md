# Дополнение 6 октября: прогулка, закрытие, рейтинги

До реализации новой поверхности сохранены PNG в `vertigo_glass/mock`; источник — текущий Docker UI /chat, гость geo-designer, fixture сообщений из capture.mjs, ru-RU, Europe/Moscow, DPR=1, zoom=100%. Размеры 1440×900, 768×1024, 390×844, 844×390, 390×544; normal/expanded, прокрутка обсуждения top/viewport/bottom. Источник панорамы — Google Maps JS, Fenway 42.345573,-71.098326; pano ID записан в artifacts.json. Ключ не сохраняется в артефактах.

Критерии для каждого размера: окружающий чат, тема, шрифты и сообщения совпадают с baseline; отступы v3 сохранены; панорама занимает сцену без обрезки атрибуции; кнопка «К началу» сверху слева; таймер 04:38; текстовая «Закрыть ×» убирает всю панель только локально; /гео вновь открывает; на телефоне только текстовый ответ; горизонтального overflow нет. Tablet normal высота450, phone normal410 при достаточной высоте; landscape и keyboard сохраняют компактную сетку.

Рейтинг зарегистрированных: постоянные очки за завершённые раунды всех партий, страна1/город3, без бонуса за скорость. Гости остаются в итогах партии, но не в постоянной таблице. Повтор polling/перезапуск не начисляет очки дважды. Тетрис сохраняет собственные правила и фильтры; общий пункт меню «Рейтинги», отдельные вкладки игр.

Это handoff, не итоговая визуальная приёмка. Требуется Docker verifier и сравнение mock/actual/side/overlay по каждому состоянию.
