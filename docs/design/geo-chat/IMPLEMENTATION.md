# Геоигра: реализация и эксплуатация

Игра открывается командой `/гео`. Пять раундов по **5 минут**, раскрытие по 10 секунд, пауза перед следующей партией 30 секунд. Вход во время игры показывает только компактную полоску; «Открыть» раскрывает панель, «Закрыть ×» убирает её локально. Без активной игры панель автоматически не появляется. Обсуждение остаётся в обычном чате.

## Панорама и ответы

Google Maps JavaScript StreetViewPanorama позволяет осматриваться, менять масштаб и переходить по доступным стрелкам. «К началу» возвращает в исходную точку; баллы всегда считаются по ней. Адресная плашка, подписи дорог, датчики движения и собственная полноэкранная кнопка Google выключены. Экземпляр панорамы не пересоздаётся при polling, изменении ответа или переключении вкладки; Google загружается только после открытия панели.

На телефоне, включая landscape, ответы только словами. На desktop/tablet карта выбора переносит страну/город в поле; отправка требует «Ответить». Страна даёт 1 балл, город 3, без бонуса за скорость. Русские/английские названия и ISO-код страны, до 120 символов, замена не чаще раза в секунду. До раскрытия другие ответы не передаются. SDK Google технически предоставляет сведения о панораме; это дружеская игра, защита от поиска места через инструменты разработчика не заявляется.

## Community-каталог и городской приоритет

Источники, лицензии, версии и стабильные ID находятся в `data/geo`. Повторный импорт не создаёт дублей. Рабочие/удалённые/непроверенные теги отсекаются; недоступный закреплённый pano ID пропускается. Исходные zoom сохранены в каталоге; стартовый интерактивный zoom=1.

Обычный подбор рассматривает общий An Arbitrary World раньше специализированного Gorgeous Touge Roads. Среди до 20 проверяемых кандидатов предпочитаются городские адреса с locality/postal_town, route и street_number; целевой выбор — минимум четыре таких точки, если они найдены. При нехватке используются остальные валидные точки. Это эвристика застройки, не визуальная гарантия отсутствия лесов/пустых улиц. В реальной проверочной партии три из пяти мест имели этот признак, все пять пришли из общего набора.

## Рейтинг и хранение

`0014_geogame.sql` хранит временное состояние комнаты с транзакционной блокировкой строки. `0015_geo_rankings.sql` хранит результаты завершённых раундов зарегистрированных игроков. Уникальность game/round/account предотвращает повторное начисление; гости остаются только в итогах партии. Топ100 сортируется по сумме очков, при равенстве — по меньшему числу сыгранных раундов, затем стабильному ключу аккаунта. В публичный ответ ключ аккаунта не передаётся.

В меню «Рейтинги» находится `/rankings`: отдельные таблицы геоигры и тетриса. Тетрис сохраняет соревнования/соло и периоды всё время/месяц. Разные системы очков не суммируются.

Pruner завершает просроченные раунды перед очисткой временных игр. Итоги партии доступны час, неактивное состояние очищается через два часа; постоянный рейтинг остаётся. Подготовка игры ограничена 45 секундами; резервирование и восстановление после отказа/отключения инициатора проверены. Не более 500 ответов за раунд.

## Настройка

- `GEO_GOOGLE_BROWSER_KEY`: публичный browser key, ограничения по HTTP referrer, Maps JavaScript API.
- `GEO_GOOGLE_SERVER_KEY`: секретный server key, ограничения по IP сервера, Street View metadata и Geocoding.
- `GEO_CATALOG_PATH`: необязательный путь, по умолчанию `/app/data/geo/catalog.json`.

Оба ключа передаются через окружение, не хранятся в исходниках/документах. Dynamic Street View тарифицируется Google отдельно от статических изображений. Атрибуцию рисует SDK; она не скрывается.

## Проверки и эталоны

Закреплённый Linux Docker: `COVERAGE_DATABASE_URL=<test postgres> sh script/verify-go-geo` создаёт отдельную базу, применяет миграции, проверяет Go race tests, двух посетителей, пять раундов, приватность, закрытие/открытие, свёрнутый вход, накопление зарегистрированного рейтинга в двух партиях и отсутствие ключей. Тестовый провайдер и управление временем существуют только в Go test binary.

`geo-live-verification.ts` проверяет настоящую community-партию, Google-панораму, карту/геокодирование, сохранение ответа и телефон. `verification/v4/walking.mjs` использует настоящий Google SDK для осмотра, перехода по улице, сохранения позиции между polling, возврата и закрытия.

Эталоны сохранены: reference-v1, design-v2, v3 (отступы), design-google (карта ответа), v4 (панорама, явное закрытие, рейтинги), v5 (свёрнутый вход). `design-v4-settled` — повтор рендера неизменённого v4 после загрузки текстур Google; исходные PNG сохранены. Ошибочные недогруженные PNG не используются как повод ухудшить реализацию.

Статус подготовки выпуска и подробная визуальная приёмка фиксируются отдельно; пока их завершение не отмечено, production не считается обновлённым.
