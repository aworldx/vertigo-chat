# Геоигра: дополнительные состояния перед реализацией

Дата: 2026-10-06. Основание — просьба пользователя «делай игру» и AGREEMENTS.md.
Применён ui-designer. Композиция v1, фон, шрифты, соседний чат и исходные ресурсы
сохранены. Изменения только внутри игры: недостающие состояния и устранение
карты на телефоне в landscape согласно прямому требованию пользователя.

PNG сохранены **до React-реализации** в `mock/`; список viewport/state/scroll
в `artifacts.json`. Абсолютный корень `/Users/amirhasanov/Projects/chat/docs/design/geo-chat/design-v2`.
Маршрут `/chat`, origin `http://127.0.0.1:4092`, Docker `chat-nice-work`, Chromium,
DPR 1, zoom 100%, ru-RU, Europe/Moscow. Гость `geo-<timestamp>`, peers
geo-designer/Клэр/moon, точные тексты fixture — `capture.mjs` и `render.mjs`.
Ресурсы — `../reference-v1/assets`, базовый CSS — копия v1 `source/proposal.css`,
дополнительные стили — `source/states.css`. Эталон v1 не изменялся.

Предварительный просмотр основных новых PNG выполнен. Функциональная и финальная
визуальная приёмка ещё не проводились. На телефоне 844×390 вкладки карты нет.
390×544 keyboard моделирует сокращение доступной высоты с фокусом в поле;
это не снимок системной клавиатуры iOS/Android.

Критерии PASS для каждой строки artifacts.json: исходная шапка/фон/композер
совпадают; высота и сетка панели соответствуют PNG; шрифты, контраст, crop и
контролы совпадают; horizontal overflow отсутствует; для place/expanded проверены
top, viewport и bottom; ответы не уходят в чат; Escape возвращает из увеличения
и списка; сворачивание возвращает sidebar. Для keyboard поле и отправка видимы.

Новые состояния: idle (запуск), loading (подготовка), error (нет подключения),
reveal (правильное место и личные баллы), finished (итоги), expanded (раскрытие),
people (список участников), keyboard. Основные place/answered/collapsed/map
сохранены для сопоставления на текущем baseline.

Рабочие правила первого выпуска: 5×60 секунд, раскрытие 10 секунд, страна 1,
город 3 балла без бонуса скорости; изменение не чаще раза в секунду до дедлайна.
Начать может вошедший в комнату человек; одна игра на комнату. После завершения
30 секунд до следующего старта. Город проверяется только при наличии locality;
поддержаны точные русские/английские названия и ISO-код страны, регистр и
разделители не важны. Произвольные опечатки не исправляются. Итоги временные,
не добавляют карму/постоянный рейтинг. Это решения первой реализации в пределах
поручения, а не утверждение, что пользователь ранее выбрал каждый параметр.

Google-проект/ключ у пользователя отсутствует. Production путь должен сообщать
об отсутствии подключения; демонстрационный снимок не выдаётся за живую панораму.
Browser-проверка использует тестовый провайдер только в тестовом сервере.
Для реального показа сохраняется Google attribution; разрешение фото в макете
не означает разрешение заменить Google изображениями из демонстрации.
