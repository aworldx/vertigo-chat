# Библиотека v2 — зафиксированный эталон

Макеты сохранены **до изменения React-компонентов** 3 октября 2026.
Визуальное направление: одобренная пользователем AI-композиция с открытым
заголовком, карточками-обложками, сериями справа и читальным залом с лампой.
Глобальные панели аккаунта и Vertigo взяты из текущего Docker-стенда без изменений.
Не перенесены выдуманные генератором меню, комментарии, просмотры, категории.

## Контракт

- Route `/library`, авторизованный `fixture01`, может публиковать; три свои статьи
  из `mockup.html`, одна серия. Даты: 03.10.2026 / 02.09.2026 / 01.09.2026.
- Chromium из закреплённого quality Docker image; zoom 100%, device scale 1.
- `mock/{width}-{top,viewport,bottom}.png`: 1440×900, 1280×676, 768×1024, 390×844.
- Независимые статические `mockup.html` + `design.css` и замороженный `baseline.css`.
- Фон `/images/library-room-v2.png`, обложки `/images/library-cover-{books,path,window}.png`.
- Шрифт заголовков: self-hosted Cormorant Garamond 500; UI: существующий Manrope;
  wordmark и неизменённое общее оформление: существующий Oswald.
- Фон fixed, `right center / cover`; mobile `auto 580px`, `right -45px`.
  Лампа — часть этого изображения, без отдельного crop или подмены.
- Desktop: открытый header, контент 77% ширины, отступ слева 9%, серии 260px справа.
  Mobile: компактная полоса фильтров выше карточек, не растущая со числом серий.
- Три декоративные AI-обложки назначаются стабильно по ID статьи. Это не генерация
  по содержанию статьи и не новая функция backend.

## Приёмка

Все строки обязательны: baseline chrome, высоты/первый экран, шрифты, фон,
лампа/слой/crop, кнопки, overflow, top/viewport/bottom. Для каждой нужны исходный PNG,
реальный Docker PNG, side-by-side и overlay/diff. До появления полного комплекта
доказательств итог — **НЕ ПРИНЯТО**. Изменение реализации не разрешает перегенерацию
эталонов. Скриншот пользователя с расхождением отменяет прежний результат.

`capture.mjs` запускается только в Docker; он не импортирует React-приложение.
Исходники и PNG макета сохранены в репозитории. Результаты сравнения — в `review/`.

Редактор: отдельные независимые `editor-mockup.html`, `editor-design.css`, PNG в
`mock-editor/` при тех же размерах. Пустая новая статья, `fixture01`, вкладка редактора,
сохранение disabled. Это дополнение зафиксировано до изменения рабочего редактора.
Старый прямоугольный crop лампы исключён из этого макета и реализации.

`script/verify-target-web` теперь завершает функциональный прогон обязательным
`compare.mjs --check` для списка и редактора. Нет PNG / другой размер / больше
0.005% пикселей с разницей канала >12/255 / средняя ошибка канала >0.12 — стоп.
Это проверка на отклонение, не автоматическая приёмка. Скрипт не пишет в `mock/`
и `mock-editor/`. Финальное визуальное решение по-прежнему требует просмотра PNG.
`test-comparison.mjs` проверяет, что контроль действительно отвергает изменённый
участок и другой viewport; исходные макеты он не меняет.
