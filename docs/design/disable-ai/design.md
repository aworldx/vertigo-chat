## Критерии приёмки — для каждого viewport

- PASS только если окружающий интерфейс, навигационная ссылка, заголовок, фон и палитра совпадают с эталоном.
- PASS только если типографика и переносы строк соответствуют mock PNG.
- PASS только если поля дат, фильтры, быстрые периоды и кнопка «Показать историю» сохраняют размеры, выравнивание и состояния.
- PASS только если нет кнопки AI Summary, подсказки входа ради Summary и упоминания Summary в подсказке дат.
- PASS только если высоты блоков и первый экран совпадают с mock PNG: на mobile все содержимое видно без горизонтального переполнения; на desktop форма сохраняет текущую ширину и выравнивание.
- PASS только если нет горизонтального переполнения на обоих viewport.
- Декоративные assets и scroll-sensitive слои отсутствуют; дополнительные scroll states не требуются для этого изменения.

Строгий итоговый review выполняется после основного verifier, отдельно по двум viewport, только по сохранённой тройке mock/current/side-by-side с overlay или diff.
