# Тетрис: локальный игровой цикл

Эталоны зафиксированы до изменения UI-адаптера 4 октября 2026. Внешний вид не меняется.
Генератор: `capture.mjs`; исходный интерфейс и CSS служат ресурсами композиции.
Сцена: `/chat`, восстановленная соло-игра, guest, имя на поле «Игрок», пауза,
120 очков, 1 линия; точные клетки/фигура/очередь заданы в генераторе.
Для стабильности сцены список сообщений/участников за модальным окном скрыт
через `#chat-room { visibility:hidden }`; интерфейс игры не изменён.
Viewport = размер PNG, DPR=1, zoom=100%, reduced-motion=reduce.

PNG: `/Users/amirhasanov/Projects/chat/docs/design/tetris-cycle/mock/`:
1440x900 (desktop), 768x1024 (tablet), 390x844 (mobile), 844x390 (landscape),
520x760 (компактная сцена; настоящий popup отдельно проверяется функционально).

Ресурсы: текущие `apps/web/css/tetris.css`, `apps/web/css/web.css`,
`apps/web/src/features/tetris/ui/Board.tsx`, `PiecePreview.tsx`, текущие локальные шрифты.
Новых фонов, шрифтов и управляющих элементов нет.

Приёмка каждого размера: PASS/FAIL для композиции, chrome, высоты первого экрана,
шрифтов, фона, клеток и цветов Canvas, превью фигур, контролов, overflow.
Сцена должна совпасть с макетом при идентичных данных. Сохранить актуальный PNG,
side-by-side и diff; открыть и проверить каждую тройку после browser-сценариев.
Функциональная приёмка: видимая новая фигура сразу после сброса, неподвижные
зафиксированные клетки, мгновенная очистка, локальная гравитация без ответов
сервера, отсутствие переигрывания старого ввода после reconnect.
