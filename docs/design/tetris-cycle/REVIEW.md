# Тетрис: результат проверки локального цикла

4 октября 2026. Проверка выполнена основным агентом по `verifier` и
`ui-designer` после реализации. Внешний вид сохранён; CSS и графика клеток
не менялись. Все оригиналы, актуальные кадры, side-by-side и diff открыты
и просмотрены в одном финальном проходе.

## Визуальная сверка — PASS

Маршрут `/chat`, восстановленная соло-игра; замороженные данные, авторизация,
DPR, viewport и способ получения макетов: [DESIGN.md](DESIGN.md).
Список участников за модальным окном скрыт только в генераторе эталонов,
чтобы он не менял сравнение; UI игры остаётся настоящим.
В каждой строке итог перечисляет: chrome / первый экран и высоты / типографика /
фон / клетки и превью (форма, цвет, положение) / кнопки / отсутствие overflow.
Все пять пар совпадают побитно: 0 отличающихся пикселей, max delta=0.
Эта приёмка подтверждает сохранение композиции; существующие тесные заголовки
резерва/очереди в landscape не перерабатывались.

## Функциональные проверки — PASS

Изолированная Linux Docker-среда из закреплённого quality-образа, отдельный
PostgreSQL 17. Ни production, ни основная локальная БД не использованы.

- `script/verify-go-tetris`: Go unit/HTTP/PostgreSQL с race, сборка, настоящий
  браузер: вход, приглашение, лимит 3, зритель, готовность, старт вдвоём,
  реванш, reload, соло/приватность, резерв, счёт, пауза, звук, leaderboard,
  mobile/touch, отдельное окно, блокировка popup и reconnect.
- На настоящем соединении ответы удерживались: движение Canvas произошло
  за 126 мс в этом прогоне, сброс сразу фиксировал клетки и показывал новую
  фигуру; следующий поворот не изменял зафиксированные клетки. Это измерение
  тестовой среды, не гарантия задержки на любом устройстве.
- На фиксированных checkpoint без последующих ответов: гравитация, мгновенная
  очистка линии, видимая новая фигура, естественная фиксация через 500 мс,
  неизменяемые лежащие клетки и правильные piece_id следующих действий.
- Воспроизведён двойной touch-drop (две команды на один tap), исправлен;
  браузер теперь требует ровно одну команду на касание.
- После pointer-нажатия кнопки звука фокус возвращается игровому полю,
  пробел сбрасывает фигуру без переключения звука. Unit дополнительно
  проверяет сохранение фокуса кнопки при клавиатурной активации.
- 20 целевых React-тестов вместе с соседним каталогом помощи.
- Общие трассы Go/TypeScript: падение, сброс, резерв, повороты, 15 сбросов
  lock delay, одиночные и четыре линии, комбо, смена уровня, отмена и
  применение мусора, top-out. Сравниваются полные состояния доски.
- Go vet и golangci-lint, полный frontend typecheck/lint и архитектурные
  границы; OpenAPI и актуальность всех DTO. OpenAPI остаётся с двумя прежними
  предупреждениями: отсутствующая license и схема приглашения, используемая
  вне HTTP-контракта.

## Границы результата

Сервер по-прежнему подтверждает результаты. Это ограниченное предсказание,
не автономная offline-игра: после двух секунд без свежего состояния показывается
«Синхронизация…», при обрыве ввод прекращается, после reconnect старые действия
не переигрываются. В сетевом матче возможна коррекция при расхождении с сервером.
Нагрузочные испытания тысяч одновременных игр и production-соединение не
проверялись. Полный `script/check` не запускался: выполнен целевой охват.
Commit, push и production не выполнялись.
