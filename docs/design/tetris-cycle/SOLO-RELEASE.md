# Независимое соло — 0.21.2

Причина: в 0.21.1 браузер всё ещё останавливал предсказание и ввод после двух секунд без снимка. Теперь solo имеет собственное время и журнал решений; сервер подтверждает журнал в фоне, самостоятельно рассчитывая результат. Сетевые матчи не переключены на клиентское время.

Проверки в закреплённой Linux Docker-среде: Go unit/race/HTTP/PostgreSQL, vet/golangci-lint; React typecheck/lint и архитектурные границы, 24 целевых engine/input/help теста, OpenAPI и актуальность всех DTO. Браузер: новый реальный solo popup/mobile с задержкой снимков 3,2 с и отключением popup на 22,5 с, локальное управление и пауза, сверка очков сервером без отката, reload; полный script/verify-go-tetris с multiplayer, observer, лобби, звуком, reconnect, mobile и рейтингом. Полный script/check не запускался.

Внешний вид сохранён по ранее зафиксированным mock из DESIGN.md. Актуальные PNG и сравнения: coverage/tetris-solo-clock/visual (в основной рабочей папке). Пять размеров 1440x900, 768x1024, 390x844, 844x390 и 520x760: исходная сцена /chat, guest, pause, 120 очков/1 линия. Автоматическое сравнение даёт ноль отличий. Сохранены оригинал, actual, side и diff.

Журнал не является долговременным offline-хранилищем: закрытие/reload до подтверждения, истечение чат-сессии или рестарт API могут помешать сохранению. Неактивная серверная запись отменяется через час. Массовая нагрузка, Safari/Firefox и физические устройства отдельно не проверялись. Миграций и изменений worker нет.

Ручная визуальная сверка выполнена: для каждого из пяти размеров лично открыты mock, current, side и diff. Chrome, размеры блоков, шрифт, фон, цвета поля, контролы и сохранение исходного overflow — PASS для каждого размера. Тесные заголовки отложенной/следующих фигур на 844x390 существуют и в оригинале; в этом исправлении композиция не менялась.

Backup перед выпуском: /opt/backups/vertigo-chat/release-0.21.2-20261004/postgres.dump, права 0600, каталог pg_restore проверен. Предыдущий API для отката: api-23632d319e9159db311dcfc3232c2f74e687b8b9. Выкладка только API; worker остаётся прежним.
