# Библиотека: изображения, серии, лайки и закладки

Макеты сохранены до реализации UI на текущем Go+React baseline. Окружение: закреплённый Docker quality image, Chromium, zoom 100%, deviceScaleFactor 1.

Viewports: 1440×900, 768×1024, 390×844. Авторизация fixture01 (id=1), can_publish=true. Фикстуры двух статей «Осенний вечер» / «Дорога домой», серия «Хроники Vertigo», описание и реакции зафиксированы в capture.mjs. Источники изображений и шрифтов: существующие /images/library-room-v2.png, /images/library-cover-{books,path,window}.png, /fonts/cormorant-garamond-variable.ttf и baseline Vertigo Text; никакой замены фона, шапки или общей типографики.

Абсолютный корень артефактов: /Users/amirhasanov/Projects/chat/docs/design/library-actions.
Исходные экраны: baseline/*.png. Эталон: mock/{width}-{state}-{position}.png.
Маршруты: list/editor/reader — /library; bookmarks — /library?bookmarks=1; series/series-editor — /library?author=1&series=Хроники%20Vertigo. Editor — новая статья, пустые поля. Reader — раскрыта первая статья с иллюстрацией «Вечер у окна». Положение прокрутки top/viewport/bottom для списка и редактора; остальные состояния top.

Критерии PASS/FAIL для каждого размера:
- Сохранены исходные шапка, фон (asset/crop/anchor/layer), шрифты и геометрия соседних элементов.
- В карточках отдельная строка лайка со счётчиком и закладки; нажатые состояния различимы, высота целей ≥44px.
- «Мои закладки» рядом с «Все статьи», фильтр не теряется при обновлении.
- У серии описание и кнопка автора; форма редактирует название и описание вместе.
- В редакторе блок обложки перед серией и кнопка «Картинка» после «Ссылка»; исходные desktop preview и mobile вкладки сохранены.
- Нет горизонтального переполнения или перекрытия контента; сохранение доступно на mobile во всех состояниях прокрутки.
- Картинки ограничены шириной текста; обложка заменяется и удаляется без потери статьи.

Финальная проверка требует actual PNG из Docker с теми же данными, side-by-side и overlay/diff для каждой строки. Эталон не перезаписывать.
