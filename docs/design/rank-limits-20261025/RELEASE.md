# Release 0.25.0 — 2026-10-25

Новая система общих лимитов по званию для хит-парада, библиотеки и фотоальбома.
Шкала для каждого типа: 1, 2, 3, 5, 8, 12, 18, 25, 35 и 50. Суточных
ограничений нет. Существующие материалы не удаляются и остаются доступны для
просмотра и редактирования. Миграции БД не требуются; выпускается только API со
встроенной React-сборкой, YouTube worker не меняется.

Целевой Docker release-gate точного дерева:

- `script/verify-go-rank-limits`: Go race unit/HTTP/PostgreSQL, все 10 уровней
  для трёх типов материалов, конкурентные запросы, повышение/понижение звания,
  production web build и browser-сценарии 1440×900, 768×1024, 390×844 — PASS.
- Соседний `script/verify-go-library`: редактор, изображения, серии, лайки,
  закладки и права доступа — PASS. Его старое сравнение снимков ожидаемо отметило
  заменённый текст фиксированной квоты и малые отклонения растеризации; эти
  устаревшие эталоны не являются приёмкой нового текста.
- Строгая визуальная приёмка новой поверхности: 42 из 42 состояний, ноль
  отличающихся пикселей. Подробности в `REVIEW.md`.

Перед публикацией дополнительно прошли TypeScript, ESLint и архитектурные
границы, Prettier, 141 frontend unit test, актуальность всех generated DTO,
gofmt, Go vet, целевой golangci-lint и production-сборки API и React. Полный
линт всего Go-модуля отдельно показывает прежний долг сложности в неизменённой
утилите `cmd/chatload`; она не входит в production API-образ. Полный
`script/check` по отдельному решению пользователя не запускался.
