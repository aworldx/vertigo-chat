## Блокеры

### BROWSER-02 — повторяющаяся ошибка MutationObserver

Во время переходов между страницами в гостевой сессии браузерная консоль
выдала повторяющуюся ошибку: `Failed to execute 'observe' on
'MutationObserver': parameter 1 is not of type 'Node'.` Без установленного
источника нельзя считать условие отсутствия ошибок в консоли выполненным.

### SERVER-01 — YouTube proxy нарушал контракт Phoenix controller (исправлено)

Все три сессии получили ошибку из live-reload frame: `expected action/2 to
return a Plug.Conn ... got: :ok`, источник —
`ChatWeb.YouTubeProxyController.phoenix_controller_pipeline/2`. Исходник
подтверждает путь ошибки: функция `stream/2` возвращает результат
`close_port/1`, то есть `:ok`, когда `chunk/2` завершается ошибкой или истекает
таймаут. В `stream/2` теперь возвращается исходный `conn` после закрытия порта.
Целевые тесты и повторный полный `mix precommit` прошли.

### ENV-01 — не настроен Хичкок (закрыто для локального прогона)

Production `OPENAI_API_KEY` получен в защищённый временный файл и передан
только локальному процессу Phoenix. Ключ не выводился и не записывался в
репозиторий. Хичкок успешно ответил на публичное обращение.

### MEDIA-01 — требуется повторить браузерную проверку воспроизведения

Production `.env` сам по себе не содержит переменную, но запущенный
production-контейнер имеет `MUSIC_PROXY_FILE` и доступ к файлу. Предоставленный
список валиден для `Chat.Music.ProxyPool`: все 1 000 прокси загрузились, а
локальный запрос вернул 15 треков. Необходимо отдельно пройти браузерные шаги
чек-листа: предпрослушивание и воспроизведение получателями. Тестовый ключ
Хичкока после проверки удалён из временной локальной директории. Временный
Phoenix-сервер с proxy-файлом подтвердил выдачу сохранённого трека (`200`,
`audio/wav`, ненулевой размер) и затем был остановлен. Встроенный браузер
падает при клике по его нативному аудио-элементу, поэтому финальную ручную
проверку воспроизведения нужно выполнить в поддерживаемом обычном браузере.

## Решение

Не выпускать релиз. До повторного полного прогона нужно локализовать
BROWSER-02, подтвердить браузерное воспроизведение музыки, выполнить сетевые
сценарии с управляемым разрывом и рестартом и пройти все неполные P0 из
таблицы вручную.
