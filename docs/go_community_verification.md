Игры и Discourse SSO отложены по явному указанию пользователя.

## Реализация

- Go Gallery: публикация изображения и thumbnail, подпись владельца, лайки,
  rank-gate, суточная/общая квоты, хранение в PostgreSQL либо S3.
- Go Library: чтение и серии, создание/редактирование владельцем, rank-gate,
  квоты, транзакционная защита при параллельной публикации.
- Go Admin: чтение таблиц только администратором; смайлы/теги — администратором
  или emoji-модератором. Права проверяются сервером для каждой операции.
- React: соответствующие страницы, редакторы, формы, ошибки/повтор, уведомления.
- Статьи: три текста и индекс, сохранённые иллюстрации и шрифты. Go выдаёт
  предварительно отрендеренный HTML с canonical/meta и содержимым без JavaScript.
- OpenAPI: `contracts/openapi/community.yaml`, сгенерированные TypeScript-типы.
  Браузерные операции используют существующую Go Accounts cookie и CSRF.

## Объяснённые различия

1. Legacy AccountBar находится под фоновым слоем. React сохраняет ранее
   внесённое исправление `relative z-10`; исходный legacy-снимок сохраняется,
   затем сравнение содержимого использует тот же слой.
2. У legacy-редактора библиотеки отсутствует `role=dialog`: CSS темы перебивает
   `position:fixed` на `relative`. React использует семантический диалог с
   удержанием фокуса/Escape. Сохраняется оригинальный снимок; сравнение стилей
   редактора отдельно добавляет legacy роль и выравнивает прокрутку фона.
3. Техническая статья описывает текущие React/Go/WebSocket вместо
   Phoenix/Elixir/LiveView в четырёх абзацах. Сохраняются обе исходные страницы;
   отдельный контроль геометрии использует прежний текст в этих четырёх местах.
4. Chromium иногда округляет каналы пикселей backdrop-filter у скруглённых
   углов. Допуск строго ограничен углами указанных элементов, числом пикселей
   и величиной канала; координаты элементов должны полностью совпадать.
   Текст, изображения и остальная геометрия не маскируются. Сам валидатор
   допуска проверяется отрицательными тестами. Пределы: обычная галерея
   32 пикселя / 4 уровня канала, редактор подписи 64 / 12, раскрытая
   библиотека 48 / 2, библиотечный редактор 12 / 1, админка 32 / 1
   (редактор тега 32 / 3). Области — только скруглённые углы с одинаковыми
   координатами; для библиотечного редактора также затемнённый фон вне панели.
   Граница нативной кнопки выбора файла вычисляется по её шрифту и отступам.
5. В галерее изменения других пользователей обновляются через опрос раз в
   5 секунд на видимой странице и при возврате фокуса вместо Phoenix PubSub.
   Собственные действия обновляют список сразу. Это отличается задержкой
   доставки внешних изменений, а не правами или сохранением данных.
6. В просмотре БД доступны дополнительные таблицы уже перенесённых Go-контекстов:
   `account_sessions`, `bot_request_receipts`, `chatlan_preferences`,
   `feedback_rate_events`, `go_schema_migrations`. Исходные снимки сохранены;
   сравнение общего оформления отдельно исключает только эти пять ссылок.
   Значения сложных типов отображаются в JSON/UTC вместо Elixir inspect.
7. Админка использует общую Go account-session вместо отдельной Phoenix
   admin-session. Модератор смайлов не получает доступ к таблицам БД.

## Результаты

Полный browser suite завершён: **72 сравнения**, 390×844, 768×1024,
1440×900. 61 пара совпала попиксельно после отдельно описанных выше
диагностических нормализаций; 11 прошли только узкую проверку округления
углов/затемнённого фона. Исходные снимки и различия сохранены; это не
утверждение, что все ненормализованные legacy-снимки совпадают с React.

Пройдены: пустые и заполненные страницы, lightbox и возврат фокуса,
вход/выход, лайк, изменение подписи, upload фото и thumbnail, серия и
раскрытие текста, создание/редактирование статьи с reload, теги и триггеры,
просмотр таблиц, загрузка/одобрение/отклонение/удаление смайла, удаление тега,
Tab/Shift+Tab в редакторах, отказ API и повтор, права emoji-модератора и
запрет чтения БД. Статьи проверены также без JavaScript с canonical/meta.

`script/verify-go-community` прошёл: реальная PostgreSQL, CSRF/ownership,
роли, нормализация, подмена владельца, whitelist таблиц, конкурентные дневные
квоты галереи и библиотеки, идемпотентные лайки. Тесты Go включают подписанные
S3-запросы к локальному fake-серверу; реальный production S3 не использовался.
`script/check-infrastructure` прошёл (OpenAPI валиден; 9 неблокирующих
предупреждений во всём наборе контрактов). Сборка React прошла.
Итоговый `mix precommit` прошёл: 411 ExUnit, 18 frontend, 3 browser,
Go lint/vet/race/build, strict TypeScript, ESLint/Prettier, проверка контрактов,
Credo и Dialyzer.
