## Область

Go обслуживает `/help` и `/ranks`; React отображает команды, десять званий,
пороги публичных сообщений/часов и открываемые возможности. Ранги приходят
из публичного `GET /api/v1/ranks`, контракт включён в profiles OpenAPI,
TypeScript генерируется из него. Правила рангов в Go Profiles domain
одинаковы для расчёта ранга пользователя и справочника; HTTP использует
application API. Новых записей, таблиц и миграций нет.

Разделы библиотеки и фотоальбома лишь упомянуты в существующих описаниях
возможностей: их UI этим этапом не перенесён. Игры не переносились.
Phoenix не изменён; proxy/fallback не добавлялись.

React разделён на API, hook загрузки/отмены/повтора и UI. При ошибке API
команды остаются доступны, справочник можно загрузить повторно.
Сохранены ссылка в именованное окно чата, исходные SVG, шрифты и CSS.
Панель аккаунта использует существующие account session/logout.

## Проверки

- Go: публичный HTTP-контракт без аккаунта/БД; обе границы каждого ранга
  (сообщения и секунды), отсутствие утечки изменяемого списка; разрешённые
  page routes и отсутствие `/games`.
- Browser: прямое открытие обоих маршрутов, reload, десять команд/рангов,
  одинаковый текст, геометрия и применённые шрифты, отсутствие overflow;
  ошибка API и успешный повтор; клавиатурный фокус ссылки в чат.
- 14 full-page пар old/new/diff: оба маршрута на ширинах
  390, 639, 640, 768, 1023, 1024, 1440. Все pixel-exact, без масок,
  CSS overrides и допуска. Высоты: 844 для 390, 1024 для 768,
  900 для остальных. Снимки и JSON:
  `apps/web/migration-results/help/`.
- Вход/выход `fixture01` проверены на 390/768/1440 (высота 900).
  Три диагностических сравнения авторизованной страницы после описанного ниже
  исправления слоя legacy — pixel-exact. Всего runner прошёл 17 сравнений.
- Исправлены отличия SVG и разбиения текста React: число с единицей
  и пробел с описанием возможности рендерятся единым текстовым узлом,
  как в legacy. Это устранило дробные сдвиги метрик/глифов.
- `mix precommit` прошёл: 411 ExUnit, 15 frontend, 3 browser,
  Go lint/vet/race/build, strict TypeScript, ESLint/Prettier,
  Credo и Dialyzer. Повторный финальный gate также прошёл (411 ExUnit).

Авторизованная панель аккаунта сохраняет существующее исправление React:
`relative z-10` поднимает её над декоративным псевдоэлементом комнаты.
Legacy-панель затемнена этим фоном. Это осознанно сохранённое исправление,
а не pixel-exact совпадение всей авторизованной страницы. Полные снимки
`*-account-old.png` / `*-account-new.png` сохраняются без масок;
текст и геометрия панели проверяются отдельно. Диагностический контроль
добавляет только `relative z-10` к панели legacy и сравнивает всю страницу
с React: этим объясняются также различия композитинга карточек ниже панели.
Снимки контроля сохраняются отдельно (`*-account-legacy-stacking-fix.png`,
`*-account-stacking-control-diff.png`); исходный legacy не выдаётся за совпавший.
После снимка классы удаляются. Фон legacy блокирует клик по выходу, поэтому
в эталоне проверяется Enter на кнопке; в React — обычный клик. Панель `AccountBar` этим этапом не изменялась.
Для входа в pinned legacy тест подключает его существующий
`account_login.js`, отсутствующий в root layout эталона; так же поступает
предыдущий `web-verification.ts`.
