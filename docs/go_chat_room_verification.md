# Общая комната: Go + React, 2026-09-22

Рабочая ветка `codex/go-react-migration`, изменения поверх `d2caf73`.
Commit, push и production не выполнялись. Игры исключены пользователем.

## Перенесённые сценарии

- Комната, composer, меню, чатлане, оформление и настройки, ранги/анкеты,
  регистрация гостя с сохранением visit/session и ротацией credential.
- Публичные и личные сообщения, адресное выделение, typing, реакции,
  удаление администратором, команды, ignore, emoji read/upload, feedback.
- Доставка: одна серая галка до ACK, две серых после ACK, две голубых после
  появления в опубликованной истории. Заблокированная отправка сохраняется
  при reload и не повторяется автоматически. Это публикация, не read receipt.
- Хичкок: bounded очередь, история, настроение, долговременная память и summary
  каждые шесть обменов; ответ публикуется до медленного обновления summary.
  Пустой ответ повторяется только с текущим вопросом, затем используется прежняя
  реплика об ошибке. Кармик: фоновая оценка, дедупликация, два изменения кармы
  пользователя за сутки, прежние анимация/мурчание и общий с Хичкоком token budget.
- Музыка через список прокси, GIF и YouTube: поиск, выбор, публикация,
  воспроизведение; YouTube URL поддерживает подготовку напрямую. 🎧 и название
  трека синхронизируются со списком участников, включая проигрыватель хит-парада.
- Хит-парад: загрузка, квота, переименование владельцем, голоса, комментарии,
  Range-аудио, PostgreSQL и S3 storage adapter.
- Передача изображений/аудио по запросу: WebRTC, fallback через очереди relay
  chunks с ACK, TTL 15 минут, сигнатуры/размеры, повтор после обрыва.
  MP3 начинает играть через MediaSource до завершения передачи; неподдерживаемые
  MSE-форматы доступны после получения файла целиком.

## Очереди, лимиты и владение

Внешний поиск выполняется двумя workers через bounded очередь 32 заданий,
Хичкок — отдельной очередью 32 заданий. Перебор музыкальных прокси выполняется
на сервере в фоне обработки поиска, с cooldown и повторным чтением файла;
клиент не получает адреса или credentials. Файл `music-proxies.txt` находится
в корне, имеет права 0600 и исключён `.gitignore`. Для локального запуска:
`MUSIC_PROXY_FILE="$PWD/music-proxies.txt"`.

Общие legacy-квоты сообщений: 3/2 секунды и 12/минуту, гостевой IP 30/минуту;
файлы 3/минуту и 10/час. Token budget Хичкока и Кармика хранится в общей
`bot_daily_usages`, включая summary. Сетевые обращения не удерживают SQL
транзакцию; shared advisory lock сериализует расходы. Комнаты и настройки
имеют единственного Go write owner; транзакции между контекстами связывает
`cmd/api`. Новых Phoenix write paths нет.

  адресат в середине текста, все три состояния галочек и blocked reload.
- Общий Bot/Karmik budget: шесть ответов + summary, точный расход, отказ при
  достижении порога; публикация ответа до summary. Кармик: дедупликация и квота

- Browser: загрузка/переименование/комментарий/проигрывание трека и 🎧 у registered и guest (включая закрытие окна),

## Границы проверки

- Прямой ICE/DataChannel в этом окружении не устанавливается даже в минимальном
  независимом примере. Рабочая передача байтов и потоковое аудио подтверждены
  через предусмотренный relay fallback; прямой P2P не объявляется проверенным.
- Private/signaling/listening hub локален одному Go-процессу; multi-instance
  routing и сохранение private dedup после рестарта требуют отдельного этапа
  до production cutover. Private feed намеренно не сохраняется в истории.
- Визуальный отчёт перечисляет конкретные проверенные состояния; он не является
  доказательством всех сочетаний настроек и всех состояний внешних плееров.
- Отдельные страницы библиотеки, фотоальбома, статей и игры не входят в этот этап.
  Ручное принятие пользователем и production rollout не выполнялись.
