# Инвентаризация миграции

Обновлено: 2026-09-23. Ветка `codex/go-react-migration`.
Статус означает локальную реализацию и проверки, не production cutover.
Подробная история и результаты — в [плане миграции](go_react_migration_plan.md).

| Сценарий | Состояние | Границы и оставшиеся действия |
| --- | --- | --- |
| Главная, вход и регистрация | Go + React, проверены | Общая Go account-session, CSRF, совместимость существующих credentials |
| Анкеты | Go + React, проверены | Чтение, редактирование, фото и права владельца |
| Общая комната, музыка и хит-парад | Go + React, проверены | WebSocket, presence, lifecycle, сообщения, медиа, команды, боты; см. отчёт комнаты |
| Ранги и справка | Go + React, проверены | Общий справочник рангов и статические страницы |
| Настройки аккаунта | Go + React, проверены | Приватный API настроек и смены email; это не включение форумного SSO |
| Визиты | Go + React, проверены | Read-only данные ChatSessions за 48 часов |
| Галерея | Go + React, проверена | Go writer, rank-gate, квоты, S3/БД, likes, подписи, React и old/new сравнение |
| Библиотека | Go + React, проверена | Go writer, ownership, серии, квоты, редактор и old/new сравнение |
| Редакционные статьи | React + Go HTML, проверены | React, статический HTML для Go, иллюстрации, SEO meta, old/new сравнение |
| Админка | Go + React, проверена | Серверные роли, просмотр БД, смайлы/теги, модерация и old/new сравнение |
| Игры и шашки | Исключены пользователем | Не переносить в текущем объёме |
| Форум / Discourse SSO | Отложен пользователем | Не переносить в текущем объёме; не считать блокером завершения остальных разделов |
| Сборка и эксплуатация | Go + React локально готовы | Phoenix исключён из целевых Docker/Compose/CI; Compose, quality gate, изолированный PostgreSQL regression и browser smoke пройдены. Production только по отдельному указанию |

## Следующий шаг

Все разделы в согласованном объёме перенесены и локально проверены. Игры и
форум не входят в этот объём. Следующее действие — отдельное решение о
production rollout; до него не делать commit, push или production-изменения
без нового указания.
