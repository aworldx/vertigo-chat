# Выпуски

Версия приложения живёт в `VERSION` и использует Semantic Versioning: `MAJOR.MINOR.PATCH`.
До версии `1.0.0` повышение `MINOR` означает новую пользовательскую возможность или заметное
изменение поведения; `PATCH` — совместимое исправление.

Перед выпуском:

1. Добавьте записи в `[Unreleased]` файла `CHANGELOG.md` с причиной изменения и видимым
   результатом.
2. Перенесите их в новый раздел с версией и датой выпуска; обновите `VERSION`.
3. Выполните `script/check`: Docker сам соберёт закреплённую Linux-среду Go + React,
   поднимет отдельную тестовую PostgreSQL и удалит тестовые контейнеры после проверки.
   Phoenix в release gate не запускается. Локальный SDK Go не нужен.
4. Закоммитьте релиз отдельным коммитом `Release vX.Y.Z`, отправьте его в `origin/main` и
   создайте аннотированный тег `vX.Y.Z` на этом коммите.
5. Отправьте тег: `git push origin vX.Y.Z`. Production разворачивается только из этого
   проверенного коммита.

Незапланированные production-исправления сначала фиксируются в `[Unreleased]`; после проверки
они получают следующий patch-релиз и тег.
